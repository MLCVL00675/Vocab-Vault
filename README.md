# ✨ VocabVault — Smart English Vocabulary & Recall Tracker

**VocabVault** is a modern, responsive personal vocabulary tracker designed to help learners expand and retain English vocabulary through date-based organization, interactive calendar filtering, spaced repetition recall grading, and intelligent linguistic & AI lookup.

---

## 🌟 Key Features

- **⚡ Lightning-Fast AI One-Step Auto-Add:**
  - Instantly look up English words to generate concise, plain-English definitions (6–12 words), contextual example sentences, and synonyms.
  - Multi-tiered lookup engine combining local caching, a built-in 180+ curated vocabulary library, concurrent Free Dictionary & Datamuse API requests, and optional Google Gemini Generative AI integration.

- **📅 Date-Based Journal & Interactive Calendar:**
  - Group vocabulary entries chronologically.
  - Interactive calendar with intuitive month navigation, quick range filters (*Today, 7 Days, 30 Days, Month, All*), and color-coded activity indicators.

- **🧠 Spaced Repetition Recall & Flashcard Practice Mode:**
  - Track confidence with intuitive tick (✓) and cross (✗) streak indicators.
  - Customizable mastery threshold (default: 5 successful recalls) that automatically transitions words from **Learning** to **🟢 Mastered**.
  - Interactive Flashcards study mode with keyboard shortcuts (`Space`, `1/x`, `2/c`, `s` for pronunciation).

- **🔊 Dual-Accent Female Voice Audio Pronunciation:**
  - High-clarity native speech synthesis supporting both **US (American)** and **UK (British)** pronunciation styles.

- **🌗 Sleek Modern UI & Dual Theme:**
  - Crafted with a custom modern design system, smooth glassmorphism, accent glows, micro-animations, and full **Dark / Light mode** support.

- **💾 Offline-First & Privacy-Focused:**
  - 100% client-side persistence using `localStorage` with JSON export/import data backup support.
